# Backlink Strategy — JollyTech / Zerox AI

A practical, white-hat plan to grow domain authority for `jollytech.ai`.
Ordered by effort-to-impact. Work through it over 60–90 days.

## 1. Fix your foundation first (Week 1)
- **Google Business Profile** — create one for JollyTech; it's the fastest
  legitimate dofollow link and gets you into local pack results.
- **Social profiles** — every profile allows a link: YouTube (@jollygamerytog),
  Instagram, X, LinkedIn company page, GitHub org. Point all of them at the
  site. These are mostly nofollow but they establish entity trust.
- **Your existing assets** — thebeacons.ai/divyamarora page and the Jolly
  Podcast (thejollypodcast.wordpress.com) already exist: make sure both link
  to jollytech.ai with "Zerox AI desktop assistant" as anchor text.

## 2. Leverage the podcast (Weeks 1–4)
- Every podcast episode description → add a site link (YouTube + WordPress).
- Show notes on the WordPress blog → write one SEO post per episode
  ("How Zerox AI automates X") linking back to /features and /pricing.
- Submit the podcast RSS to Listen Notes, Podchaser, Apple Podcasts — each
  directory entry is a backlink to your site.

## 3. Free tools as link bait (Weeks 2–6)
Your /tools page is your strongest linkable asset. Promote it:
- Post each tool individually on Reddit (r/InternetIsBeautiful, r/SideProject),
  Indie Hackers, Hacker News (Show HN), and Product Hunt.
- Answer Quora/Reddit questions like "free QR code generator?" with a genuine
  answer + your tool link. Do NOT spam — answer first, link second.
- Create simple embeds: a "QR code powered by JollyTech" footer on generated
  QR images gets you passive backlinks every time someone shares one.

## 4. Directory & listing citations (Weeks 2–4, one afternoon)
- Product Hunt launch (Zerox AI), AlternativeTo (list as Notion AI /
  Windows Copilot alternative), Slashdot, SourceForge, Capterra, G2.
- Indian startup directories: YourStory, StartUp India, F6S, Crunchbase.
- Niche AI directories: There's An AI For That, Futurepedia, AI Tools Directory.

## 5. Content that earns links (Months 2–3)
- Publish 2–3 comparison/listicle posts on a blog at jollytech.ai/blog:
  "Zerox AI vs Windows Copilot", "10 tasks you can automate on Windows
  for free", "Voice control setup guide for Windows 11".
- These rank long-tail AND give journalists/redditors something to cite.
- Add the schema markup already on the site (FAQPage) to increase CTR.

## 6. Outreach (ongoing)
- Tech YouTubers with 10k–100k subs doing "AI tools" roundups — offer a free
  lifetime license for a mention. Micro-influencers convert well.
- Local press: JollyTech is an Indian indie build — regional startup blogs
  and college tech fest newsletters often cover these for free.
- Partner with student communities (your student plan is the hook): college
  tech clubs will share a student-discount link readily.

## Rules (so you never get penalized)
- Never buy links or join link farms.
- Vary anchor text: brand ("JollyTech"), product ("Zerox AI"), and natural
  phrases ("this desktop AI assistant") — never one exact-match phrase.
- Slow and steady: 5–15 new referring domains/month is the healthy pace.
- Track everything in Search Console → Links report; disavow spam you find.
